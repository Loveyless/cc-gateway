# 1.2 Installation Guide

## Official Channels and System Requirements

For this maintenance fork, download only from **[cc-gateway GitHub Releases](https://github.com/Loveyless/cc-gateway/releases)** or this source repository. **[ccswitch.io](https://ccswitch.io)** belongs to the upstream CC Switch project, not this fork. Any site or client that asks for payment, top-ups, or login credentials is not an official distribution channel for this fork.

| System | Minimum Version | Architecture |
|--------|-----------------|--------------|
| Windows | Windows 10 or later | x64 / ARM64 |
| macOS | macOS 12 (Monterey) or later | Intel (x64) / Apple Silicon (arm64) |
| Linux | See distribution notes below | x64 / ARM64 |

## Prerequisites

### Install Node.js

The CLI tools managed by CC Gateway (Claude Code, Codex, Gemini CLI) require a Node.js environment.

**Recommended version**: Node.js 18 LTS or higher

#### Windows

1. Visit the [Node.js official website](https://nodejs.org/)

2. Download the LTS version installer

3. Run the installer and follow the prompts

4. Verify installation:

 ```bash
 node --version
 npm --version
 ```

#### macOS

```bash
# Install with Homebrew
brew install node

# Or use nvm (recommended)
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
nvm install --lts
```

#### Linux

```bash
# Ubuntu/Debian
curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash -
sudo apt-get install -y nodejs

# Or use nvm
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
nvm install --lts
```

### Install CLI Tools

#### Claude Code

**Option 1: Homebrew (recommended for macOS)**

```bash
brew install claude-code
```

**Option 2: npm**

```bash
npm install -g @anthropic-ai/claude-code
```

#### Codex

**Option 1: Homebrew (recommended for macOS)**

```bash
brew install codex
```

**Option 2: npm**

```bash
npm install -g @openai/codex
```

#### Gemini CLI

**Option 1: Homebrew (recommended for macOS)**

```bash
brew install gemini-cli
```

**Option 2: npm**

```bash
npm install -g @google/gemini-cli
```

## Windows

### Installer

1. Visit the [Releases page](https://github.com/Loveyless/cc-gateway/releases)
2. Download `CC-Gateway-v{version}-Windows.msi`
3. Double-click to run the installer
4. Follow the prompts to complete installation

### Portable Version (No Installation Required)

1. Download `CC-Gateway-v{version}-Windows-Portable.zip`
2. Extract to any directory
3. Run `cc-gateway.exe`

## macOS

### Manual Download

1. Download `CC-Gateway-v{version}-macOS.dmg` (recommended) or `CC-Gateway-v{version}-macOS.zip`
2. Open the DMG, or extract the zip to get `CC Gateway.app`
3. Drag it to the Applications folder

### Signing and Notarization Status

This maintenance fork currently has no published macOS signing or notarization guarantee. Verify the release assets and signatures before installing a build.

## Linux

### ArchLinux

No CC Gateway AUR package is published yet. Use the AppImage or build a package locally from source.

### Debian / Ubuntu

1. Download `CC-Gateway-v{version}-Linux-x86_64.deb` or `CC-Gateway-v{version}-Linux-arm64.deb` for your architecture
2. Install:

```bash
sudo dpkg -i CC-Gateway-v{version}-Linux-*.deb

# If there are dependency issues
sudo apt-get install -f
```

### AppImage (Universal)

1. Download `CC-Gateway-v{version}-Linux-x86_64.AppImage` or `CC-Gateway-v{version}-Linux-arm64.AppImage` for your architecture
2. Add execute permission:

```bash
chmod +x CC-Gateway-v{version}-Linux-*.AppImage
```

3. Run:

```bash
./CC-Gateway-v{version}-Linux-*.AppImage
```

## Verify Installation

After installation, launch CC Gateway:

1. The app window displays correctly
2. A CC Gateway icon appears in the system tray
3. The app switcher shows enabled managed apps, and you can switch to the target app panel

## Updates

In-app automatic updates are disabled for the first maintenance release, and the app does not read the upstream CC Switch update manifest. Back up `~/.cc-gateway/cc-gateway.db`, then download and install new versions manually from this project's Releases page.

## Uninstall

### Windows

- Uninstall via "Settings > Apps"
- Or run the uninstaller in the installation directory

### macOS

- Move `CC Gateway.app` to Trash
- Optional: Delete the configuration directory `~/.cc-gateway/`

### Linux

```bash
# Debian/Ubuntu
sudo apt remove cc-gateway
```

AppImage requires no uninstall step; delete the downloaded `CC-Gateway-*.AppImage` file.
