# 1.2 インストールガイド

## 公式チャネルとシステム要件

このメンテナンス版は **[cc-gateway GitHub Releases](https://github.com/Loveyless/cc-gateway/releases)** または本リポジトリのソースから入手してください。**[ccswitch.io](https://ccswitch.io)** は上流 CC Switch プロジェクトのサイトであり、本版の公式サイトではありません。支払い、チャージ、ログイン情報の入力を求めるサイトやクライアントは、本版の公式配布先ではありません。

| システム | 最低バージョン | アーキテクチャ |
|------|----------------|----------------|
| Windows | Windows 10 以上 | x64 / ARM64 |
| macOS | macOS 12 (Monterey) 以上 | Intel (x64) / Apple Silicon (arm64) |
| Linux | 下記ディストリビューション説明を参照 | x64 / ARM64 |

## 前提条件

### Node.js のインストール

CC Gateway が管理する CLI ツール（Claude Code、Codex、Gemini CLI）には Node.js 環境が必要です。

**推奨バージョン**：Node.js 18 LTS 以上

#### Windows

1. [Node.js 公式サイト](https://nodejs.org/) にアクセス

2. LTS バージョンのインストーラーをダウンロード

3. インストーラーを実行し、指示に従ってインストール

4. インストールの確認：

 ```bash
 node --version
 npm --version
 ```

#### macOS

```bash
# Homebrew でインストール
brew install node

# または nvm を使用（推奨）
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
nvm install --lts
```

#### Linux

```bash
# Ubuntu/Debian
curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash -
sudo apt-get install -y nodejs

# または nvm を使用
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
nvm install --lts
```

### CLI ツールのインストール

#### Claude Code

**方法 1：Homebrew（macOS 推奨）**

```bash
brew install claude-code
```

**方法 2：npm**

```bash
npm install -g @anthropic-ai/claude-code
```

#### Codex

**方法 1：Homebrew（macOS 推奨）**

```bash
brew install codex
```

**方法 2：npm**

```bash
npm install -g @openai/codex
```

#### Gemini CLI

**方法 1：Homebrew（macOS 推奨）**

```bash
brew install gemini-cli
```

**方法 2：npm**

```bash
npm install -g @google/gemini-cli
```

## Windows

### インストーラー方式

1. [Releases ページ](https://github.com/Loveyless/cc-gateway/releases) にアクセス
2. `CC-Gateway-v{バージョン}-Windows.msi` をダウンロード
3. インストーラーをダブルクリックして実行
4. 指示に従ってインストール

### ポータブル版（インストール不要）

1. `CC-Gateway-v{バージョン}-Windows-Portable.zip` をダウンロード
2. 任意のディレクトリに展開
3. `cc-gateway.exe` を実行

## macOS

### 手動ダウンロード

1. `CC-Gateway-v{バージョン}-macOS.dmg`（推奨）または `CC-Gateway-v{バージョン}-macOS.zip` をダウンロード
2. DMG を開く、または zip を展開して `CC Gateway.app` を取得
3. 「アプリケーション」フォルダにドラッグ

### 署名・公証の状態

本メンテナンス版には現在、macOS の署名・公証に関する公開保証がありません。インストール前にリリース資産と署名状態を確認してください。

## Linux

### ArchLinux

CC Gateway 独自の AUR パッケージはまだ公開していません。AppImage を使用するか、ソースからローカルでパッケージをビルドしてください。

### Debian / Ubuntu

1. アーキテクチャに合わせて `CC-Gateway-v{バージョン}-Linux-x86_64.deb` または `CC-Gateway-v{バージョン}-Linux-arm64.deb` をダウンロード
2. インストール：

```bash
sudo dpkg -i CC-Gateway-v{バージョン}-Linux-*.deb

# 依存関係に問題がある場合
sudo apt-get install -f
```

### AppImage（汎用）

1. アーキテクチャに合わせて `CC-Gateway-v{バージョン}-Linux-x86_64.AppImage` または `CC-Gateway-v{バージョン}-Linux-arm64.AppImage` をダウンロード
2. 実行権限を追加：

```bash
chmod +x CC-Gateway-v{バージョン}-Linux-*.AppImage
```

3. 実行：

```bash
./CC-Gateway-v{バージョン}-Linux-*.AppImage
```

## インストールの確認

インストール完了後、CC Gateway を起動します：

1. アプリウィンドウが正常に表示される
2. システムトレイに CC Gateway のアイコンが表示される
3. アプリ切り替えに有効化された管理対象アプリが表示され、目的のアプリパネルへ切り替えられる

## 更新

最初のメンテナンス版ではアプリ内自動更新を無効にしており、上流 CC Switch の更新マニフェストも読み取りません。`~/.cc-gateway/cc-gateway.db` をバックアップしてから、このプロジェクトの Releases ページで新しいバージョンを手動でダウンロードしてインストールしてください。

## アンインストール

### Windows

- 「設定 → アプリ」からアンインストール
- またはインストールディレクトリのアンインストーラーを実行

### macOS

- `CC Gateway.app` をゴミ箱に移動
- オプション：設定ディレクトリ `~/.cc-gateway/` を削除

### Linux

```bash
# Debian/Ubuntu
sudo apt remove cc-gateway
```

AppImage にアンインストール手順はありません。ダウンロードした `CC-Gateway-*.AppImage` ファイルを削除してください。
